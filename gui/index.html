Welcome to Video Notes

Video Notes turns lecture videos into study notes using a few other programs: ffmpeg, an AI model (the Claude CLI by default, or an API or a model on this PC), and, for videos without subtitles, Python with Whisper speech-to-text. Below is what was found on this PC. Set up what's missing now, or later from this Dependencies tab.

Nothing is installed unless you press Install: it first shows the exact command, then runs it in a PowerShell window you can watch, where any license or administrator prompts appear. You can also copy the commands and run them yourself. The list re-checks when a setup window closes; npm run check runs the same check in a terminal.
